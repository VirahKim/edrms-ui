# Q-Bits EDMS

Electronic Document Management System (EDMS) web application, part of the Q-Bits Systems suite.

Q-Bits Systems is an AI powered Enterprise Resource Planning (ERP) platform comprising:
* Accounting
* Wallet System
* Inventory
* Asset Management
* Procurement
* Sales & POS
* HR & Payroll Management
* Visitor Management
* Document Management
* Project Management

This repository contains the web UI for the **Document Management** module.
